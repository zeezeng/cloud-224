# 一键部署说明

## 1. GitHub Actions 镜像方案

GitHub Actions 负责构建并推送镜像到 GHCR，服务器只负责拉取镜像并启动容器，不再在服务器本地构建前后端。

## 2. 自动发布规则

以下情况会自动发布镜像：

- 推送到 `master`
- 推送 `v*` 标签
- 手动触发 `Publish Docker Image` 工作流

镜像标签规则：

- `ghcr.io/zeezeng/cloud-224:latest`
- `ghcr.io/zeezeng/cloud-224:<commit_sha>`
- `ghcr.io/zeezeng/cloud-224:<tag>`（打标签时）

工作流文件见 [publish-image.yml](/F:/MyCodes/cloud-224/.github/workflows/publish-image.yml)。

## 3. 服务器部署

建议先把 [install.sh](/F:/MyCodes/cloud-224/deploy/install.sh) 上传到服务器，再执行：

```bash
scp deploy/install.sh root@你的服务器IP:/opt/cloud-224/install.sh
```

如果 GHCR 镜像是公开的，直接执行：

```bash
bash /opt/cloud-224/install.sh
```

如果 GHCR 需要登录拉取：

```bash
GHCR_USERNAME=你的GitHub用户名 GHCR_TOKEN=你的token bash /opt/cloud-224/install.sh
```

脚本会自动：

- 安装 Docker / Compose
- 写入本地 `docker-compose.yml`
- 生成 `.env`
- 拉取镜像并启动 `mysql`、`redis`、`app`

## 4. 本地构建

如果你本地仍然需要从源码构建：

```bash
docker compose -f docker-compose.yml -f docker-compose.build.yml up -d --build
```

## 5. 常用命令

查看日志：

```bash
cd /opt/cloud-224
sudo docker compose logs -f app
```

更新到最新镜像：

```bash
cd /opt/cloud-224
sudo docker compose pull
sudo docker compose up -d
```
