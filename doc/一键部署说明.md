# 一键部署说明

## 1. 私有仓库方案

仓库保持私有，GitHub Actions 负责构建并推送镜像到 GHCR，服务器只拉镜像，不再拉源码。

## 2. 镜像发布

每次推送到 `master` 或打 `v*` 标签，会自动发布镜像：

- `ghcr.io/<owner>/<repo>:latest`
- `ghcr.io/<owner>/<repo>:<commit_sha>`
- `ghcr.io/<owner>/<repo>:<tag>`（打标签时）

## 3. 服务器部署

私有仓库下，`deploy/install.sh` 需要先放到服务器一次，再执行：

```bash
scp deploy/install.sh root@你的服务器IP:/opt/cloud-224/install.sh
```

```bash
GHCR_USERNAME=你的GitHub用户名 GHCR_TOKEN=你的read:packages令牌 bash install.sh
```

脚本会自动：

- 安装 Docker / Compose
- 登录 GHCR
- 写入本地 `docker-compose.yml`
- 拉取镜像并启动 `mysql`、`redis`、`app`

## 4. 本地构建

如果你想从源码本地构建：

```bash
docker compose -f docker-compose.yml -f docker-compose.build.yml up -d --build
```

## 5. 常用命令

查看日志：

```bash
cd /opt/cloud-224
sudo docker compose logs -f app
```

更新到最新镜像：

```bash
cd /opt/cloud-224
sudo docker compose pull && sudo docker compose up -d
```
