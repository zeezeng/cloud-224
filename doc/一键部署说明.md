# 一键部署说明

## 1. 公开仓库方案

仓库改为公开后，服务器可以直接拉源码，再使用 Docker Compose 本地构建启动。

## 2. GitHub 上改为公开仓库

在 GitHub 仓库页面操作：

1. 打开仓库 `Settings`
2. 拉到最下方 `Danger Zone`
3. 进入 `Change repository visibility`
4. 选择 `Change to public`

## 3. 服务器部署

直接执行：

```bash
curl -fsSL https://raw.githubusercontent.com/zeezeng/cloud-224/master/deploy/install.sh | bash
```

脚本会自动：

- 安装 Git、Docker、Docker Compose
- 克隆或更新公开仓库代码
- 安装 Docker / Compose
- 自动生成 `.env`
- 构建并启动 `mysql`、`redis`、`app`

## 4. 本地构建

仓库拉到本地后直接执行：

```bash
docker compose up -d --build
```

## 5. 常用命令

查看日志：

```bash
cd /opt/cloud-224
sudo docker compose logs -f app
```

更新到最新镜像：

```bash
cd /opt/cloud-224
git pull
sudo docker compose up -d --build
```
