# 一键部署说明

## 1. GHCR 部署方案

生产环境直接拉取 GHCR 已构建好的应用镜像，不在服务器上构建源码。部署过程只依赖服务器本地的 Docker、curl 和网络访问能力。

默认部署参数：

- 部署文件地址：`https://raw.githubusercontent.com/zeezeng/cloud-224/master`
- 部署目录：`/opt/cloud-224`
- 应用端口：`8080`

## 2. 一键部署

在服务器执行：

```bash
curl -fsSL https://raw.githubusercontent.com/zeezeng/cloud-224/master/deploy/install.sh -o install.sh
chmod +x install.sh
```

首次执行时传入关键配置：

```bash
APP_IMAGE=ghcr.io/你的GitHub用户名/cloud-224 \
APP_IMAGE_TAG=latest \
GHCR_USERNAME=你的GitHub用户名 \
GHCR_TOKEN=你的GHCR令牌 \
MYSQL_ROOT_PASSWORD=请改成强密码 \
./install.sh
```

脚本会自动：

- 安装 `curl`、Docker / Compose
- 下载 `docker-compose.yml` 和 `.env.example`
- 生成或更新 `.env`
- 创建 MySQL、Redis、上传文件数据目录
- 登录 `ghcr.io`
- 拉取并启动 `mysql`、`redis`、`app`

> 注意：生产配置写在 `/opt/cloud-224/.env` 中，后续重新执行脚本时会继续沿用。

## 3. 常用配置

`.env` 位于部署目录，例如 `/opt/cloud-224/.env`。常用变量：

```bash
APP_PORT=8080
JAVA_OPTS=-Xms512m -Xmx512m -Dfile.encoding=UTF-8
APP_IMAGE=ghcr.io/你的GitHub用户名/cloud-224
APP_IMAGE_TAG=latest
GHCR_USERNAME=你的GitHub用户名
GHCR_TOKEN=你的GHCR令牌
MYSQL_ROOT_PASSWORD=root
MYSQL_DATABASE=mars-system
REDIS_PASSWORD=
```

修改 `.env` 后重新启动：

```bash
cd /opt/cloud-224
sudo docker compose pull app
sudo docker compose up -d
```

## 4. 更新部署

方式一，重新执行一键脚本：

```bash
APP_IMAGE_TAG=latest ./install.sh
```

方式二，在服务器手动更新：

```bash
cd /opt/cloud-224
sudo docker compose pull app
sudo docker compose up -d --remove-orphans
```

## 5. 常用命令

查看服务状态：

```bash
cd /opt/cloud-224
sudo docker compose ps
```

查看应用日志：

```bash
cd /opt/cloud-224
sudo docker compose logs -f app
```

重启服务：

```bash
cd /opt/cloud-224
sudo docker compose restart app
```
