# 一键部署说明

## 1. 服务器一条命令部署

适用于全新 Linux 服务器。脚本会自动完成以下动作：

- 安装 Docker 与 Docker Compose（如未安装）
- 从 GitHub 拉取或更新代码
- 自动生成 `.env`
- 启动 `mysql`、`redis`、`app` 三个容器

直接执行：

```bash
curl -fsSL https://raw.githubusercontent.com/zeezeng/cloud-224/master/deploy/install.sh | bash
```

## 2. 自定义部署目录或分支

例如部署到 `/srv/cloud-224`：

```bash
curl -fsSL https://raw.githubusercontent.com/zeezeng/cloud-224/master/deploy/install.sh | APP_DIR=/srv/cloud-224 BRANCH=master bash
```

如果要切换成自己的仓库地址：

```bash
curl -fsSL https://raw.githubusercontent.com/zeezeng/cloud-224/master/deploy/install.sh | REPO_URL=https://github.com/你的账号/cloud-224.git BRANCH=master bash
```

## 3. 首次部署后需要做的事

脚本首次会自动从 `.env.example` 生成 `.env`。如果你要改端口、数据库密码、Redis 密码，可以编辑：

`/opt/cloud-224/.env`

改完后重新执行同一条部署命令，脚本会自动更新并重启容器。

## 4. 常用命令

查看应用日志：

```bash
cd /opt/cloud-224
sudo docker compose logs -f app
```

重新构建并启动：

```bash
cd /opt/cloud-224
sudo docker compose up -d --build
```

停止服务：

```bash
cd /opt/cloud-224
sudo docker compose down
```
