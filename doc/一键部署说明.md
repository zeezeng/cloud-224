# 一键部署说明

## 1. Git 部署方案

生产环境采用 Git 部署：服务器拉取本仓库代码，并在服务器上通过 Dockerfile 构建前端与后端镜像。部署过程只依赖服务器本地的 Git、Docker 和网络访问能力。

默认部署参数：

- 仓库地址：`https://gitee.com/382444017/cloud-224.git`
- 分支：`master`
- 部署目录：`/opt/cloud-224`
- 应用端口：`8080`

## 2. 一键部署

在服务器执行：

```bash
curl -fsSL https://gitee.com/382444017/cloud-224/raw/master/deploy/install.sh | bash
```

如果需要指定仓库、分支或部署目录：

```bash
curl -fsSL https://gitee.com/382444017/cloud-224/raw/master/deploy/install.sh \
  | GIT_REPO_URL=https://gitee.com/382444017/cloud-224.git GIT_BRANCH=master APP_DIR=/opt/cloud-224 bash
```

脚本会自动：

- 安装 `git`、`curl`、Docker / Compose
- 首次部署时 `git clone` 到 `APP_DIR`
- 后续部署时 `git fetch` 并重置到 `origin/GIT_BRANCH`
- 生成 `.env`（如果已存在则保留）
- 创建 MySQL、Redis、上传文件数据目录
- 执行服务器构建并启动 `mysql`、`redis`、`app`

> 注意：后续部署会将服务器上的 Git 工作副本重置到远程分支。生产配置请写入 `.env`，不要直接修改被 Git 跟踪的配置文件。

## 3. 常用配置

`.env` 位于部署目录，例如 `/opt/cloud-224/.env`。常用变量：

```bash
APP_PORT=8080
JAVA_OPTS=-Xms512m -Xmx512m -Dfile.encoding=UTF-8
MYSQL_ROOT_PASSWORD=root
MYSQL_DATABASE=mars-system
REDIS_PASSWORD=
NODE_REGISTRY_URL=https://registry.npmmirror.com
MAVEN_MIRROR_URL=https://repo.maven.apache.org/maven2
```

修改 `.env` 后重新启动：

```bash
cd /opt/cloud-224
sudo docker compose -f docker-compose.yml -f docker-compose.build.yml up -d --build
```

## 4. 更新部署

方式一，重新执行一键脚本：

```bash
curl -fsSL https://gitee.com/382444017/cloud-224/raw/master/deploy/install.sh | bash
```

方式二，在服务器手动更新：

```bash
cd /opt/cloud-224
sudo git fetch --prune origin +refs/heads/master:refs/remotes/origin/master
sudo git checkout -B master origin/master
sudo git reset --hard origin/master
sudo docker compose -f docker-compose.yml -f docker-compose.build.yml up -d --build --remove-orphans
```

## 5. 常用命令

查看服务状态：

```bash
cd /opt/cloud-224
sudo docker compose ps
```

查看应用日志：

```bash
cd /opt/cloud-224
sudo docker compose logs -f app
```

重启服务：

```bash
cd /opt/cloud-224
sudo docker compose restart app
```
