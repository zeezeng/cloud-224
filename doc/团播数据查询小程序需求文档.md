## 1. 项目概述

### 1.1 产品定位

团播数据查询小程序是面向团播业务场景的数据查询工具，用于集中展示主播资料、主播流水、流水排行、本月与上月对比、用户乐享值排行、主播金库余额等信息。

产品首期按“公开查询工具”设计，所有用户均可查看核心数据；后台保留管理员能力，用于配置平台接口、维护主播展示资料、管理数据同步状态。

### 1.2 目标用户

| 用户类型 | 使用目标 |
| --- | --- |
| 普通用户 | 查询主播资料、流水排行、主播金库余额、用户乐享值排行 |
| 团播运营 | 查看主播日、周、月流水表现，判断主播增长或下滑趋势 |
| 管理员 | 配置接口凭证、触发数据同步、查看同步状态、维护主播展示资料 |

### 1.3 数据来源

首期数据通过直播平台接口同步获取，主要包括：

- 主播基础资料
- 主播直播间信息
- 主播流水数据
- 用户乐享值数据
- 主播金库余额数据
- 主播图片或视频素材

如平台接口存在权限限制，系统后台需支持接口凭证配置、定时同步、手动同步和同步失败提示。

## 2. 产品目标

### 2.1 核心目标

- 用户可以快速查询主播资料、流水数据、排行数据和金库余额。
- 用户可以查看乐享值排行榜，并按用户昵称或用户 ID 查询。
- 团播运营可以直观看到主播日、周、月流水表现。
- 支持本月与上月同期数据对比，辅助判断主播增长或下滑趋势。

### 2.2 首期成功标准

- 支持按主播名称、直播间号搜索主播。
- 支持查看主播详情、照片或视频、直播间号、流水数据和金库余额。
- 支持查看主播日榜、周榜、月榜流水排行。
- 支持展示本月流水与上月同期流水对比，包括金额差值和百分比变化。
- 支持查看用户乐享值从高到低排行榜。
- 所有核心页面在微信小程序和抖音小程序中正常展示。

## 3. 用户与权限

### 3.1 用户类型

| 用户类型 | 权限说明 |
| --- | --- |
| 普通用户 | 可查看主播资料、流水排行、主播金库、用户乐享值排行 |
| 管理员/运营 | 可配置数据同步接口、查看同步状态、管理主播资料展示内容 |

### 3.2 可见性规则

首期产品按全部用户可见设计，但需遵循以下保护规则：

- 不在前端展示平台接口密钥、后台同步日志等敏感信息。
- 主播金库金额仅展示业务允许公开的余额字段。
- 用户手机号、真实姓名、身份证、提现账户等隐私字段不在前端展示。
- 用户头像、昵称、乐享值可公开展示。
- 如后期改为内部工具，可增加登录鉴权和角色权限。

## 4. 功能需求

### 4.1 首页

首页用于展示核心数据入口、整体概览信息和榜单摘要。

#### 页面内容

| 模块 | 内容 |
| --- | --- |
| 顶部搜索框 | 支持搜索主播名称、直播间号、用户昵称 |
| 快捷入口 | 主播资料、流水排行、乐享值排行、主播金库 |
| 数据概览 | 今日总流水、本周总流水、本月总流水、主播总数、乐享值用户总数 |
| 榜单摘要 | 今日流水 Top 3 主播、本月流水 Top 3 主播、乐享值 Top 3 用户 |

#### 交互要求

- 点击搜索结果后，进入对应主播详情页或用户乐享值详情页。
- 点击榜单卡片后，进入完整排行榜页面。
- 数据加载失败时展示失败提示和重试按钮。
- 所有金额类数据统一展示最近更新时间。

### 4.2 主播资料列表页

主播资料列表页用于展示所有主播的卡片列表，支持搜索、筛选和排序。

#### 展示字段

- 主播头像或封面图
- 主播名称
- 直播间号
- 所属团播/团队
- 当前状态：直播中、未开播、停播、未知
- 本月流水
- 乐享值相关指标，可选
- 金库余额入口

#### 功能要求

- 支持按主播名称搜索。
- 支持按直播间号搜索。
- 支持按团队筛选。
- 支持按流水排序。
- 支持按开播状态筛选。
- 点击主播卡片进入主播详情页。

### 4.3 主播详情页

主播详情页展示单个主播的完整资料、媒体素材、流水表现和金库余额。

#### 基础资料

| 字段 | 说明 |
| --- | --- |
| 主播名称 | 主播展示名称 |
| 主播头像 | 主播头像图片 |
| 直播间号 | 平台直播间编号 |
| 主播 ID | 平台主播唯一标识 |
| 所属团队 | 团播或运营团队 |
| 主播简介 | 后台可维护的展示文案 |
| 开播状态 | 直播中、未开播、停播、未知 |
| 最近开播时间 | 最近一次开播时间 |
| 主播照片 | 支持多图预览 |
| 主播视频 | 可选，默认不自动播放 |

#### 数据模块

- 今日流水
- 本周流水
- 本月流水
- 上月同期流水
- 本月较上月同期变化金额
- 本月较上月同期变化比例
- 当前流水排名
- 主播金库余额
- 最近更新时间

#### 交互要求

- 点击直播间号可复制。
- 点击照片或视频可预览。
- 点击流水模块进入主播流水明细页。
- 点击金库模块进入主播金库详情页。

### 4.4 主播流水查询

主播流水查询用于查询主播在不同周期下的流水数据。

#### 查询维度

| 维度 | 说明 |
| --- | --- |
| 日流水 | 按自然日统计 |
| 周流水 | 按自然周统计，默认周一至周日 |
| 月流水 | 按自然月统计 |
| 自定义时间范围 | 二期功能 |

#### 查询条件

- 主播名称
- 直播间号
- 时间范围
- 所属团队
- 排名区间

#### 展示字段

- 排名
- 主播头像
- 主播名称
- 直播间号
- 流水金额
- 较上一周期变化金额
- 较上一周期变化比例
- 最近更新时间

#### 排行规则

- 默认按流水金额从高到低排序。
- 日榜按自然日统计。
- 周榜按自然周统计，默认周一至周日。
- 月榜按自然月统计。
- 本月对比上月时，首期采用“本月累计 vs 上月同期”，避免月初数据失真。

### 4.5 流水排行页

流水排行页用于集中展示主播流水排行榜。

#### 页面 Tab

- 日榜
- 周榜
- 月榜
- 本月对比上月

#### 榜单字段

| 字段 | 说明 |
| --- | --- |
| 排名 | 当前筛选周期内排名 |
| 主播头像 | 主播头像图片 |
| 主播名称 | 主播展示名称 |
| 直播间号 | 平台直播间编号 |
| 流水金额 | 当前周期流水金额 |
| 环比变化 | 与上一周期或上月同期对比 |
| 趋势标识 | 上升、下降、持平 |

#### 排名规则

- 排名实时根据当前筛选周期计算。
- 相同流水金额时，可按主播 ID 或更新时间排序。
- 环比变化为正显示增长，负数显示下降，零显示持平。

### 4.6 用户乐享值排行榜

用户乐享值排行榜用于展示用户乐享值排名，并支持查询单个用户乐享值信息。

#### 列表展示字段

- 排名
- 用户头像
- 用户昵称
- 用户 ID，可选
- 乐享值
- 最近更新时间

#### 列表功能

- 默认按乐享值从高到低排序。
- 支持搜索用户昵称或用户 ID。
- 支持分页或下拉加载。
- 支持查看用户乐享值详情。

#### 用户乐享值详情

- 用户头像
- 用户昵称
- 当前乐享值
- 当前排名
- 乐享值更新时间
- 乐享值来源明细，二期功能

### 4.7 主播金库

主播金库用于查看主播剩余金额。

#### 金库列表页字段

- 主播头像
- 主播名称
- 直播间号
- 金库余额
- 最近更新时间

#### 金库详情页字段

- 主播名称
- 直播间号
- 当前金库余额
- 累计收入，可选
- 累计支出，可选
- 最近更新时间
- 金库变动明细，二期功能

#### 查询能力

- 按主播名称查询。
- 按直播间号查询。
- 按余额从高到低排序。
- 按余额从低到高排序。

#### 7.1.1 乐享值排行榜接口（当前小程序直连接入）

当前 `pages/enjoy/enjoy` 页面已直接接入云团一簇公开接口，用于获取乐享值用户榜单。该接口不经过本项目后端，但微信小程序上线前需在小程序后台配置合法请求域名 `https://api.dongdongne.com`，用户头像域名建议配置 `https://apic.douyucdn.cn`。

| 项目 | 内容 |
| --- | --- |
| 接口名称 | 获取用户乐享值排行榜 |
| 请求地址 | `https://api.dongdongne.com/api/live/user/list` |
| 请求方式 | `POST` |
| 请求头 | `Content-Type: application/json`；`X-Project: 182102` |
| 前端方法 | `getEnjoyUserList(params)` |
| 认证方式 | 当前直连公开接口，前端请求配置 `skipAuth: true` |
| 分页规则 | `page` 从 1 开始；当前小程序每页固定请求 20 条 |
| 搜索规则 | 关键词为空时查询榜单；关键词不为空时按 `nickname`、`name` 模糊查询；纯数字关键词额外按 `uid` 模糊查询 |
| 前端文件 | `mars-uniapp/src/api/enjoy.ts` |

请求参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| page | number | 否 | `1` | 页码，从 1 开始 |
| size | number | 否 | `20` | 每页条数，当前前端常量 `ENJOY_PAGE_SIZE` 为 20 |
| keyword | string | 否 | 空字符串 | 前端入参，不直接透传；有值时转换为 `search` 条件 |
| search | array | 否 | 无 | 接口查询条件，由前端根据 `keyword` 生成 |

无搜索请求体示例：

```json
{
  "page": 1,
  "size": 20
}
```

昵称搜索请求体示例：

```json
{
  "page": 1,
  "size": 20,
  "search": [
    {
      "key": "nickname",
      "value": "%脚皇%",
      "condition": "LIKE",
      "relationship": "OR",
      "type": "CONDITION"
    },
    {
      "key": "name",
      "value": "%脚皇%",
      "condition": "LIKE",
      "relationship": "OR",
      "type": "CONDITION"
    }
  ]
}
```

纯数字关键词搜索时，前端会额外追加 `uid` 条件：

```json
{
  "page": 1,
  "size": 20,
  "search": [
    {
      "key": "nickname",
      "value": "%488801793%",
      "condition": "LIKE",
      "relationship": "OR",
      "type": "CONDITION"
    },
    {
      "key": "name",
      "value": "%488801793%",
      "condition": "LIKE",
      "relationship": "OR",
      "type": "CONDITION"
    },
    {
      "key": "uid",
      "value": "%488801793%",
      "condition": "LIKE",
      "relationship": "OR",
      "type": "CONDITION"
    }
  ]
}
```

```json
{
  "code": 0,

    "size": 20,
    "count": {},
    "page": 1,
    "list": [
      {
        "creator": "sys",
        "modifier": "sys",
        "avatar": "avatar/default/16_middle",
        "pointsNum1": 600200,
        "pointsNum2": 17992580,
        "modificationDateTime": "2025-12-20 23:49:07",
        "room": "182102",
        "platform": "DOU_YU",
        "uid": "488801793",
        "name": "用脚点礼物",
        "nickname": "脚皇",
        "id": 31103,
        "attribute": "{}",
        "pointsTotal": 18592780,
        "remarks": "",
        "creationDateTime": "2025-12-20 23:49:07"
      }
    ]
  },
  "message": "SUCCESS"

```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | number | 接口业务状态码，`0` 表示成功 |
| message | string | 接口返回消息 |
| data.total | number | 符合条件的数据总数 |
| data.size | number | 当前分页大小 |
| data.page | number | 当前页码 |
| data.count | object | 接口预留统计对象 |
| data.list | array | 用户乐享值记录列表 |
| list[].id | number/string | 接口记录 ID |
| list[].uid | number/string | 平台用户 ID，前端用于用户 ID 搜索和副标题展示 |
| list[].name | string | 用户展示名称 |
| list[].nickname | string | 用户昵称 |
| list[].avatar | string | 用户头像，可能是斗鱼相对路径；前端会补全为 `https://apic.douyucdn.cn/upload/...jpg` |
| list[].pointsNum2 | number/string | 当前用于页面展示的乐享值原始字段，前端按 `/100` 归一化展示 |
| list[].pointsNum1 | number/string | 其他积分字段，当前仅保留不展示 |
| list[].pointsTotal | number/string | 总积分字段，当前仅保留不展示 |
| list[].room | string | 所属直播间号 |
| list[].platform | string | 数据平台，例如 `DOU_YU` |
| list[].modificationDateTime | string | 最近更新时间 |
| list[].creationDateTime | string | 创建时间 |

前端展示映射：

| 页面字段 | 来源字段 | 处理规则 |
| --- | --- | --- |
| 用户名称 | `name` 或 `nickname` | 优先使用 `name`，为空时使用 `nickname` |
| 用户 ID | `uid` | 用于搜索和副标题展示 |
| 用户头像 | `avatar` | 相对路径自动补全斗鱼 CDN 地址 |
| 乐享值 | `pointsNum2` | 优先读取 `pointsNum2`，兜底读取 `points_num2`、`pointsNum`、`points_num`、`value`、`score`、`num` |

接口处理要求：

- 乐享值展示值需与前端保持一致：原始字段转数字后，绝对值大于等于 100 时按 `/100` 后取整；小于 100 时直接取整。
- 头像字段可兼容 `avatar`、`avatarUrl`、`avatar_url`、`headImg`、`head_img`；相对路径需补全为斗鱼 CDN 图片地址。
- 接口异常时页面不弹出默认错误 Toast，由乐享值页面自行展示空态、重试或保留历史数据。

### 7.2 平台同步接口

后台需要对接直播平台接口，支持同步：

- 主播资料
- 主播直播间信息
- 主播流水
- 用户乐享值
- 主播金库余额
- 主播图片或视频素材

### 7.3 同步策略

| 数据类型 | 同步频率 | 说明 |
| --- | --- | --- |
| 主播资料 | 每天 1 次 | 支持手动刷新 |
| 主播流水 | 每 10-30 分钟 1 次 | 保留上一次成功数据 |
| 乐享值排行 | 每 10-30 分钟 1 次 | 保留上一次成功数据 |
| 主播金库 | 每 10-30 分钟 1 次 | 保留上一次成功数据 |

同步失败时：

- 保留上一次成功数据。
- 页面展示最近成功同步时间。
- 后台记录失败原因。
- 前端提示“数据更新失败，当前展示为最近一次成功同步数据”。

## 8. 统计口径

### 8.1 流水

流水指主播在指定周期内产生的有效收入金额，具体口径以平台接口返回字段为准。

### 8.2 日流水

按自然日统计，时间范围为当天 00:00:00 至 23:59:59。

### 8.3 周流水

按自然周统计，默认周一至周日。

### 8.4 月流水

按自然月统计，时间范围为每月 1 日至月末。

### 8.5 本月对比上月

首期采用“本月累计 vs 上月同期”：

- 本月累计：本月 1 日至当前日期。
- 上月同期：上月 1 日至上月对应日期。
- 变化金额 = 本月累计流水 - 上月同期流水。
- 变化比例 = 变化金额 / 上月同期流水。
- 如上月同期流水为 0，则变化比例显示为“--”。

### 8.6 乐享值

乐享值指用户在平台内产生的乐享值积分，具体含义和计算方式以平台接口为准。

### 8.7 主播金库

主播金库指主播当前可查询的剩余金额，具体口径以平台接口返回的金库余额字段为准。

## 9. 非功能需求

### 9.1 性能

- 首页首屏加载时间不超过 2 秒。
- 榜单分页加载，每页建议 20-50 条。
- 图片使用压缩图或 CDN 地址。
- 视频默认不自动播放，避免影响加载速度。

### 9.2 兼容性

- 适配微信小程序、抖音小程序。
- 页面布局适配常见手机屏幕。
- 榜单、卡片、详情页在窄屏下不出现内容遮挡。

### 9.3 安全与合规

- 平台接口密钥只保存在服务端。
- 小程序前端不得直接请求直播平台敏感接口。
- 金库、流水等金额数据需要确认是否允许公开展示。
- 用户隐私字段不展示。
- 所有接口增加访问频率限制，避免被恶意刷取。

### 9.4 数据准确性

- 所有数据页面必须展示“最近更新时间”。
- 同步失败时不得展示错误金额。
- 金额类数据统一保留两位小数。
- 排行榜排序逻辑前后端保持一致。
